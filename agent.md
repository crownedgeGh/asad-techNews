# Agent Rules & Guidelines

## Responsive Design
- You must write code that is fully responsive, supporting all screens: mobile, tablet, and web views.

## Theming & UI
- All UI should be theme-based.
- UI must support both Light and Dark modes.

## Typography
- All text must follow the desired fonts specified in `plan.md`:
  - Body/article text: Merriweather, Georgia, Source Serif 4, Lora
  - Headings: Inter, Roboto, Helvetica Neue, Source Sans 3
  - Tech/news editorial look: Source Serif 4 + Inter
  - Very smooth on screen: Georgia, Merriweather
  - Modern minimal look: Inter + Source Serif 4
